# DraftDigger
WebApp d’aide à la décision pour League of Legends : à partir de la compo alliée et ennemie, elle recommande le meilleur pick, les runes, le build et les items à acheter en cours de partie, avec explications. Commence sur Yorick, puis s’étend à tous les champions. Moteur de règles et calcul de stats, données Data Dragon.
